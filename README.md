# STOKAI 🚀
> **Gestion de Stock & Prise de Commande**  
> *Plateforme SaaS mobile-first pour commerçants sénégalais.*

## 🌟 Vision
STOKAI est une solution complète conçue pour digitaliser le commerce de proximité au Sénégal. Elle permet aux commerçants de gérer leurs stocks et leurs ventes avec une interface premium, tout en offrant aux clients une expérience d'achat fluide via une marketplace intégrée.

## 📁 Structure du Projet
Le projet est organisé en monorepo simplifié :
- **/stokai-front** : Application mobile (iOS/Android) et interface Web d'administration développée avec Ionic 7, Angular 17 et Nx.
- **/stock-ai-backend** : API REST robuste développée avec Spring Boot 3 (Java 21) et PostgreSQL.
- **SPECS-FONCTIONNELLES-V1.1.md** : Cahier des charges complet et suivi d'avancement.

## 🚀 Fonctionnalités Clés
- **Dashboard Marchand** : Suivi des ventes et du bénéfice net en temps réel.
- **Gestion de Stock** : Inventaire, alertes de seuil, variantes de produits et scan de codes-barres.
- **Marketplace** : Catalogue public permettant aux clients de commander en ligne.
- **Paiements Mobiles** : Intégration prévue de Wave et Orange Money.

## 🛠️ Stack Technique
- **Frontend** : Angular 17, Ionic 7, Capacitor, Nx, SCSS.
- **Backend** : Java 21, Spring Boot 3, Spring Security (JWT), Hibernate, Flyway.
- **Base de données** : PostgreSQL, Redis.
- **Services** : Firebase (Push), Africa's Talking (SMS).
